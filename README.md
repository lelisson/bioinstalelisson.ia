## Publicar no GitHub Pages

1. Crie um repositório no GitHub (exemplo: `lelisson-ia`).
2. Envie esta pasta (`index.html` e `simbolo.svg`) para a branch `main`.
3. No GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Copie a URL (ex.: `https://SEUUSUARIO.github.io/lelisson-ia/`) e cole em **Editar perfil → Links** no Instagram.
